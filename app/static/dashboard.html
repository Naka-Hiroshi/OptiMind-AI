        Starting from a clean install

        The lightest Windows 11 comes from a fresh install: the official Microsoft ISO on a USB drive plus an autounattend.xml answer file that removes bloat and applies tweaks while Windows installs. It erases the PC, so back up first.

        • Schneegans unattend generator: builds the answer file in your browser
        • UnattendedWinstall: a ready-made answer file
        • Official Windows 11 download

        Where these tweaks come from

        • WinUtil by Chris Titus Tech
        • Win11Debloat by Raphire
        • Sparkle by Parcoil

        Left out on purpose: turning off Defender, BitLocker, UAC or updates, removing Edge or built-in apps, and "set services to manual" presets. They weaken security, can't be cleanly undone, or break features such as Mobile Hotspot. Core isolation's Memory integrity is the one security setting offered, kept apart and never applied in bulk, because Microsoft itself lists turning it off as an option for gaming.

        What OptiMind found

        Checking your devices and drivers…

        Updates

        Only from the sources Microsoft points to: Windows Update, where drivers are signed through Microsoft's hardware program, and the makers' own sites. OptiMind creates a restore point before it installs anything, never installs a driver older than yours or any firmware (such as a BIOS), and waits while a game is running.

        The makers' own apps

        AMD, Intel and PC makers deliver some drivers through their own app, which knows your exact model. OptiMind opens one you have, with your normal rights, and links only to the maker's own page. These apps can also offer BIOS updates: OptiMind never installs one, and if you do, follow the maker's steps with the PC on reliable power.

        Drivers apps added

        Kernel drivers that belong to no device: anti-cheat, antivirus, virtual machines, VPNs, fan and RGB control, virtual audio. They run with the same rights as Windows, so OptiMind lists who made each one and flags known risks. Windows' own drivers aren't listed.

          Back up and restore

          A copy of every driver package from other makers, with a list of what each device used. Keep it on another drive than Windows: after a clean reinstall, one click installs them all back.

          Where drivers should come from

            Left out on purpose: "driver updater" apps and download sites. Security companies flag many of them as unwanted software: they bundle other programs, scare with inflated scan results to sell a license, and fetch drivers from unofficial places. Windows Update and the makers' own sites are where drivers come from.

            Startup apps

            Uses the same switch as Task Manager → Startup apps, so you can change it here or there. Changes take effect at your next sign-in. Apps for "All users" can be changed while OptiMind runs as administrator.
