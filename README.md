# OptiMind AI

OptiMind AI keeps Windows 11 responsive. The app you're using gets the PC
first, busy background apps are held back, and idle memory goes back to
Windows. While you play, it measures each game's frame rate and tells you
what holds it back: the graphics card, the processor or a frame cap.

## Download

Get **OptiMind-AI-Setup** from the
[newest release](https://github.com/Naka-Hiroshi/OptiMind-AI/releases/latest),
run it and follow Setup. It works on any Windows 11 PC or laptop (64-bit).

- Windows may show "Windows protected your PC", because the file isn't
  signed with a paid certificate: click **More info**, then **Run anyway**.
- Each release lists the Setup file's SHA-256. To check your download,
  open Terminal in the folder with the file, run
  `(Get-FileHash .\OptiMind-AI-Setup-<version>.exe).Hash`
  and compare the two.
- OptiMind 1.5.0 and newer say in **Settings → About** when a newer
  version is out here. They never download or install anything by
  themselves.

This page only holds the releases: OptiMind's code isn't published.
